# СОФИТ — сайт школы синхронного плавания

Статический сайт на чистом HTML/CSS/JavaScript (vanilla), без фреймворков,
сборщиков и backend. Принцип разработки — **mobile-first** (базовая вёрстка
под 375–414px, адаптация под планшет/десктоп через media queries от 768px).

## Структура проекта

```
СОФИТ/
├── index.html            # Главная (Hero-секция на весь экран)
```

### 2026-08-11 (исправление 4 багов: overflow / центрирование карточек / кнопка «Наверх» / header)
- **Баг 1 — горизонтальный скролл всей страницы на trainers.html (375px)**: корневая причина — у flex-элементов `min-width: auto` по умолчанию, поэтому `.trainer-card` с фото 270px + padding не могла ужаться до своего `flex-basis` и распирала ленту шире viewport (footer при этом «не дотягивался» до краёв). Исправлено: `min-width: 0` на `.trainer-card`; глобальная защита `html, body { overflow-x: hidden; max-width: 100%; }` в начале `css/style.css`.
- **Баг 2 — первая карточка не отцентрирована при загрузке**: `scroll-snap-align: start` заменён на `center`, добавлен `scroll-padding-inline` на `.trainers-scroller`; карточка на мобильном = 100% контентной области ленты при симметричных inline-отступах 10% — при `scrollLeft = 0` первая карточка по центру экрана, справа виден краешек следующей. На десктопе ≥1024px отступы возвращаются к 20px (карточки в ряд).
- **Баг 3 — кнопка «Наверх» не докручивала до верха**: прокрутка теперь строго на уровне `window.scrollTo({ top: 0, behavior: 'smooth' })` + фолбэк на `documentElement`/`body` (после `overflow-x: hidden` на html/body скроллером в некоторых браузерах становится body); чтение позиции скролла — через `window.scrollY || documentElement.scrollTop || body.scrollTop`. `scroll-padding-top`/`scroll-margin-top` в проекте не используются (проверено).
- **Баг 4 — переполнение header на 375px** (после добавления Instagram кнопка «Записаться» наезжала на иконку телефона): на мобильном <768px скрыта иконка VK в header (`.header-contacts a[aria-label="VK"] { display: none; }`), на десктопе ≥768px VK снова видна. В footer и на contacts.html VK не скрывалась.
- HTML-структура страниц, модалка, `js/modal.js`, `css/modal.css` не изменялись — только `css/style.css`, `js/main.js` и README.
